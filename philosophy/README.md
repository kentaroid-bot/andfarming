# 哲学と背景

## 本書の目的

『あんど農法』の目的は、**なるべく外部から肥料などの資材を与えなくても、作物がよく育つ仕組みを知り、畑に整えること**です。

作物を育て、収穫することが第一です。無肥料や不耕起を守ること自体を目的にはしません。作物が育たないときは必要な介入を行い、その原因と結果を観察します。根、草、微生物、土壌中の養分、水、酸素が働く範囲を広げることで、外部資材を必要とする場所、量、期間を少しずつ減らします。

本書は、その仕組みを考え、試し、改善するための判断軸を整理します。栽培手順だけでなく、なぜその手順を選ぶのか、どのような観察から生まれたのか、どこまでが確認でき、どこからが仮説なのかを記録します。文章や理論の完成は目的ではなく、作物をよりよく育てるための手段です。

## 基本の考え方

- 作物が必要とする時期に、根、水、酸素、養分を確保する。
- 草、残渣、生きた根を使い、圃場内の養分を回収して次作へつなぐ。
- 雑草が作物を圧迫するときは、場所と時期を限定して主導権を移す。
- 生育が止まるときは無投入に固執せず、必要な介入で作物を支える。
- 介入の結果を記録し、次回はより少ない外部資材で育てられる方法を探す。
