# 観察記録

このディレクトリでは、実際の栽培記録を年ごと、地域ごと、作物ごとに残します。

成功例だけでなく、失敗例、判断に迷ったこと、次回試すことも重要な栽培知です。

## 推奨する置き方

```txt
records/
  2026/
    2026-05-29-tomato-example.md
```

## 記録に入れたいこと

- 日付
- 地域、気候
- 土質
- 作物、品種
- 前作
- 作業内容
- 入れた資材
- 草の扱い
- 水分状態
- 生育の様子
- 病虫害
- 収量、味
- 今回の仮説
- 次回の改善案

新しい記録を書くときは、[../templates/record.md](../templates/record.md) をコピーして使います。
