Open Source Cultivation Method

自然の自律性と、人間の小さな介入を両方使う。

『あんど農法』は、不耕起とスポット耕起、無肥料ベースとC/N調整、 草の放置と利用を組み合わせる栽培メソッドです。

READMEを読む GitHub

What is And Farming?

対立ではなく、場所と時間で統合する。

あんど農法は、土壌を一度きりの資材投入先ではなく、 炭素・窒素・微生物・植物が相互に調整し続ける生きたインフラとして扱います。 中心に置くのはC/N比、草、根、微生物、そして時間差です。

Principles

基本原理

01

C/N比で土を見る

高炭素、均衡、高窒素のグラデーションとして土と有機物を捉え、 作物ごとに必要な調整を小さく試します。

02

場所と時間を分ける

畑全体は不耕起、植え穴だけ整える。冬は草を育て、 春は若草やマルチとして使います。

03

土壌状態を先に整える

施肥を作物への給餌だけでなく、根が下りる環境のC/Nバランス調整として扱います。

Practice

実践の流れ

  1. 観察する 土の硬さ、草、水分、前作、葉色を見て、C過多・N過多・酸欠などの仮説を立てる。
  2. 全体は動かさない 根穴、菌糸、団粒構造を壊しすぎないよう、畑全体の耕起を最小限にする。
  3. 株元だけ整える 種まきや定植の場所だけ浅くほぐし、必要なら少量の資材でC/Nを調整する。
  4. 草を使う 草をマルチ、土寄せ材、炭素源、窒素源、根穴づくりとして役割ごとに扱う。

Recipes

作物リレーの例

落花生 AND 冬大根

マメ科の根粒菌と残渣を利用し、冬大根の初期生育を助けます。

えんどう豆 AND 夏のウリ類

春まで育ったマメ科残渣を、夏のキュウリやカボチャの栄養供給に使います。

Open Source

成功も失敗も、栽培知として共有する。

あんど農法は検証中のメソッドです。地域、土質、品種、天候によって結果は変わります。 観察記録、作物別レシピ、失敗例、改善案、参考文献の追加を歓迎します。
