# 水やり

水やりは、量よりもタイミングと土壌状態の観察を重視します。

## 観察すること

- 表土だけが乾いているのか、根の深さまで乾いているのか。
- 草マルチの下に湿り気が残っているか。
- 葉が朝からしおれているか、昼だけしおれて夕方に戻るか。
- 畝の水はけは良いか、過湿になっていないか。

## 基本方針

- 活着前の苗には、根が土となじむまで水を切らさない。
- 活着後は、根が深く伸びるように、浅く頻繁な水やりを避ける。
- 草マルチで乾燥と地温上昇を抑える。
- 過湿による酸欠にも注意する。

## 梅雨明けの山畑: ピンポイント深層給水

水が限られる梅雨明けの山畑では、畝全体へ浅く広く撒く余裕がなく、株の近くへ深くゆっくり染み込ませる給水が現実的な選択になります。ただし、これは水がない畑だけの応急処置ではありません。水道や用水路がある場所でも、必要な場所へ深く届け、表面蒸発を減らし、根を下へ誘導するという基本は同じです。

### やり方

1. 株元から約10cm離した場所に、小さな凹みを作る。
2. その凹みへ1株あたり1L程度の水を注ぐ。
3. 表面に溢れて横へ流れないよう、土への染み込みに合わせて少しずつ注ぐ。
4. まとまった雨が降るまでは、2日に1回程度を目安に続ける。

### 狙い

- 水を根より深い土中へ届け、直射日光による表面蒸発を減らす。
- 植物の根は、水分が通過して湿りが残った場所をたどるように伸びやすい。水を表面で止めず、土深くまで長く通過させることで、根もその水の通り道に沿って下へ長く伸びやすくなる。
- 深い層へ根を誘導し、乾燥に強い根群を育てる。
- 過剰な水やりで根腐れや水依存を招かず、降雨まで株を維持する。

### 判断の目安

- 水が表面を横へ走る場合は、一度に注ぐ量が多すぎる。
- 翌朝もしおれが戻らない場合は、水量、頻度、根の深さ、草マルチの不足を見直す。
- 土が重く湿り続ける場所では、同じ頻度で続けず、過湿と酸欠を優先して確認する。
- 川沿いの元田んぼなど、一定の深さで水が抜けにくい畑では、水やりだけでなく[畝立て](ridge-making.md)で水が通る縦方向の距離を確保する。

## 記録したいこと

- 水やりした日付と量
- 天候、気温、風
- 草マルチの有無
- 翌日の葉色、しおれ、成長
