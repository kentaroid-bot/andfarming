# 水やり

水やりは、量よりもタイミングと土壌状態の観察を重視します。

## 観察すること

- 表土だけが乾いているのか、根の深さまで乾いているのか。
- 草マルチの下に湿り気が残っているか。
- 葉が朝からしおれているか、昼だけしおれて夕方に戻るか。
- 畝の水はけは良いか、過湿になっていないか。

## 基本方針

- 活着前の苗には、根が土となじむまで水を切らさない。
- 活着後は、根が深く伸びるように、浅く頻繁な水やりを避ける。
- 草マルチで乾燥と地温上昇を抑える。
- 過湿による酸欠にも注意する。

## 記録したいこと

- 水やりした日付と量
- 天候、気温、風
- 草マルチの有無
- 翌日の葉色、しおれ、成長
